# Paperclip: Autonomous AI Agent Orchestration Control Plane

Paperclip is an open-source orchestration control plane designed to manage teams of AI agents as if they were an organized engineering company.

## 🌐 Live Website & Documentation
- **GitHub Pages**: [https://rifaterdemsahin.github.io/paperclip/](https://rifaterdemsahin.github.io/paperclip/)
- **Local Preview**: `http://localhost:30095/index.html`

---

## 🤖 Why Use Paperclip for Hermes, Grokbot, ChatGPT & Claude?

Modern AI agents excel in specialized domains, but running them in isolation leads to context fragmentation, runaway token bills, and zero governance. Paperclip unifies them into an accountable workforce:

| Agent / Model | Superpower in Paperclip | Role |
| :--- | :--- | :--- |
| **Hermes Agent** *(Nous Research)* | Autonomous runtime, self-learning loops, persistent skills, long-term memory | **Lead Worker / Executor** |
| **Grokbot** *(xAI)* | High-throughput dialectic reasoning, real-time web scout, contrarian analysis | **The Critic & Devil's Advocate** |
| **ChatGPT / o-Series** *(OpenAI)* | High-level goal decomposition, JSON schema creation, DAG planning | **Project Lead / Architect** |
| **Claude Cowork** *(Anthropic)* | 200k+ context window, deep code reviews, architectural critique & security | **QA & Principal Reviewer** |

---

## 🚀 Key Features

1. **Agent Org Chart & Reporting Lines**: Define who delegates to whom, who reviews diffs, and who can trigger deployments.
2. **Hard Spend Caps & Token Guardrails**: Per-agent and per-task budget limits preventing runaway loops.
3. **Heartbeat Scheduler & Persistent State**: Asynchronous task dispatch with health monitoring and audit trails.
4. **Cross-Model Dialectic Consensus**: Grokbot and Hermes stress-test plans before code is executed.
